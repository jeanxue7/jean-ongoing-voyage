# 网站框架提案 v0.1

日期：2026-09-19。状态：待确认。

## 概念

一条穿过森林、沙漠、雪山的个人徒步路线。访客跟着重装徒步小人前进，在沿途认识主人的写作、酒吧与生活经历。暂用「金子」作为项目称呼，正式站名待用户决定。

参考链接：https://longtailwriter.com/ 。本次网页工具无法读取，浏览器访问也超时，尚未验证该站实际视觉与交互。以下为根据用户描述提出的独立方案，不是对参考站的复刻或已完成审计。

## 内容与场景

| 位置 | 场景入口 | 内容 | 点击后的结果 |
| --- | --- | --- | --- |
| 起点 | 徒步者、路牌、路线总览 | 名字、一句话介绍、三个主要方向 | 开始探索，或直接跳到指定栏目 |
| 森林 | 林间书桌、旅行手账、收音机 | 公众号：旅行写作、原野人生播客系列、年终总结 | 分类列表，再进入文章详情或原文；播客先链接原平台 |
| 沙漠 | 绿洲里的小酒吧 | 酒吧介绍、我的选酒、小程序、空间照片 | 酒款故事、空间相册、到店信息、小程序入口 |
| 雪山 | 山峰群、营地手账、手绘地图 | 关于我、徒步山峰、非洲公益、中国与世界旅行足迹 | 个人经历页、山峰相册、公益故事、地点相册 |
| 终点 | 营地信箱 | 联系方式 | 邮件、公开社交账号、用户选择公开的二维码 |

这些景观是叙事安排，不暗示酒吧真的位于沙漠，或公益地点属于某种自然环境。

个人信息在首页提供简短入口，完整内容置于雪山场景的「关于我」，并可从固定导航直达，避免重要信息必须走完全程才出现。

## 推荐互动

电脑端：向下滚动推进徒步路线。人物随进度沿路移动，远山、树木与前景产生轻微视差；停止滚动后人物停步。每个场景控制在 2–4 个有名称的可点击入口，悬停或键盘聚焦时明确反馈。

点击入口后打开可独立分享的内容页；返回时恢复原来的场景位置。文章与大量照片在内容页阅读，探索首页保持清楚、轻盈。

手机端：竖向三段场景，用滑动推进和点击进入；不依赖悬停，也不强迫用户拖动很长的横向地图。阅读时停止场景动画。保留「写作 / 酒吧 / 关于我 / 联系」导航。

提供减少动态效果的静态浏览方式；所有内容都可以通过普通链接和键盘访问。声音如后续加入，默认关闭。

## 人物与视觉提案

首选：有手绘笔触的 2.5D 立体小人，搭配分层绘本景观。用插画的体积感和层次创造立体效果。真正可以任意旋转的 3D 角色需要额外建模与动作绑定，是否采用在风格确认后决定。

人物参考：用户提供的 `2.jpg`。保留黄色帽子、墨镜、红色外套、浅蓝重装包、黄绿色裤子的识别特征。照片已足够启动风格探索；若需要面部更像本人，再补一张无遮挡的正脸照片。

下一阶段先制作一张全身人物风格样张，以及一个森林场景的桌面/手机 UI。确认后才制作侧面、背面与走路动作素材，避免各张人物风格不一致。

森林偏绿、沙漠偏赭黄、雪山偏冷蓝；人物红色外套贯穿所有场景。文字面板保持统一材质和阅读对比度，正文使用清晰字体，手写风格只用于少量路牌和标题。

## 首版范围

首版包括：三个场景、人物随滚动前进、直接导航、写作三类入口、酒吧介绍与选酒、空间相册、小程序入口、关于我、少量代表山峰与旅行地点、公益故事、联系方式。

先用精选内容打通整条访问路径，再扩充全部地点与文章。不在首版加入账号系统、酒类交易系统、复杂游戏任务或文章自动同步。小程序先展示已提供的二维码与使用说明；是否可以直接跳转，待用户提供实际入口并在目标浏览器验证。

旅行文章和旅行地图引用同一条内容记录：从故事和地点两个方向找到它，避免重复维护。

## 制作顺序

1. 框架确认：确定场景归属、探索方式与首版重点。
2. 视觉试样：人物样张、森林场景、桌面和手机布局。
3. UI 扩展：其余场景、文章列表、详情、相册、地图和联系方式。
4. 前端骨架：页面路由、场景、导航、内容数据与响应式布局。
5. 功能细化：逐个设计入口、状态、返回行为和异常情况。
6. 验收与备份：真实内容替换、手机与桌面检查、本地版本保存、GitHub 同步。
