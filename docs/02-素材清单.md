# 素材收集清单

不需要一次性准备完。先给代表内容即可；文字可以是粗稿、链接或现有笔记。

## 第一批：足够开始人物与 UI

| 素材 | 建议数量 | 说明 |
| --- | --- | --- |
| 人物参考 | 已有 1 张 | 当前徒步照片可用；正脸照仅在需要提高面部相似度时补充 |
| 显示名字与一句话介绍 | 各 1 条 | 希望别人怎么称呼你、记住你什么 |
| 公众号名称与入口 | 1 组 | 名称、链接或二维码 |
| 代表内容 | 3–6 条 | 旅行文章、原野人生、年终总结各选 1–2 条；标题、链接、一句话推荐理由 |
| 酒吧名称与介绍 | 1 组 | 名称、城市、50–150 字介绍、最想让别人感受到什么 |
| 酒吧代表照片 | 3–5 张 | 门头、整体空间、你最喜欢的角落 |
| 代表山峰或旅行地点 | 3 个 | 名称、时间、各 2–3 张照片、一句话记忆 |

## 第二批：填充完整网站

| 模块 | 需要的内容 |
| --- | --- |
| 关于我 | 100–300 字自述；中国科学院大学的专业/时间（愿意公开时）；大厂 PM 经历的公司、时间与职责；希望表达的人生态度 |
| 旅行写作 | 标题、日期、摘要、封面、原文链接；如站内全文展示，再提供正文 |
| 原野人生 | 系列介绍、封面、单集标题、嘉宾（若有）、简介、收听链接；有音频授权和文件后再考虑站内播放器 |
| 年终总结 | 年份、标题、封面、原文链接或正文 |
| 选酒 | 酒款名称、图片、你的推荐语、风味描述；价格与在售情况仅在希望展示且能维护时加入 |
| 酒吧空间 | 空间故事、6–12 张精选图、地址/营业时间（希望展示时）、地图链接 |
| 小程序 | 小程序名称、二维码、已可用的分享链接（若有）；无需账号密码 |
| 徒步山峰 | 山峰/路线名称、地区、年月、短故事、每条 4–8 张图；海拔、里程只填已知准确数据 |
| 非洲公益 | 国家/地区、时间、项目名称、你做了什么、个人感受、4–8 张适合公开的照片及说明 |
| 旅行足迹 | 城市/地区、国家、年月、短故事、关联照片与文章；标明去过或计划去，地图默认仅显示去过 |
| 联系方式 | 想公开的邮箱、微信二维码或其他社交账号；选 1–2 个主要方式即可 |

照片优先提供原图或高清 JPG/PNG；横竖皆可，每组最好有一张适合宽幅封面的图。保留本地原图，网页使用另外压缩的副本。涉及他人的照片请标出是否可公开，尤其公益活动中的合照。

## 本地收集位置

把原始素材按 `assets-originals/avatar/`、`writing/`、`bar/`、`hiking/`、`volunteering/`、`travel/`、`contact/` 分类放置。同一次旅行可再建一个地点文件夹。文件名与故事里的引用保持一致即可，不必先做复杂整理。
