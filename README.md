# 金子的个人网站

当前阶段：Opening 与 Chapter 01–04 的首图已经确认，五屏静态可点击原型已经完成；下一步进入动态素材验证与正式前端工程。

## 项目文件

- **最新视觉方向：`design/外部AI设计简报-v2.md`**：摄影感户外、小人物与大地形；旧版绘本 UI 不作为实施定稿。用户负责外部图片探索，Codex 主要负责代码。

- **视觉定稿映射：`design/external-v2/scene-manifest.json`**：锁定 Opening 与 Chapter 01–04 的最终首图，开发时不得按最高版本号猜测素材。
- **动态开发计划：`docs/07-视觉定稿与动态开发计划.md`**：采用静态母版、AI 环境微动与网页滚动动画的混合方案。
- **五屏交互原型：`prototype/journey-interactions-v1/index.html`**：串联 Opening、01、02、03、04；包含生活实验三条轨迹、创作记录对话与翻书、酒吧 H5、地点气球与地图层级。
- `design/ui-references-v1/`：Opening 与 01 的网页主视觉排版参考；实施版文字与按钮仍由 HTML 渲染。

- **最新内容交接：`docs/06-内容交接.md`**：用户确认文案、外部 UI 进度、24 篇文章库与首页精选建议。
- `content/site-copy.json`：首屏与近况原句；`content/articles-index.json` 与 `content/articles/`：文章索引与完整本地正文。

- **最新方案：`docs/04-首页结构-v0.2.md`**：五章节个人叙事首页，手绘徒步路线串联；优先于旧版场景分类。
- `docs/05-素材索引.md` 与 `content/source-links.json`：已收到的目录、文章链接及读取状态。

- `docs/01-网站框架.md`：内容结构、互动方式、首版范围与制作顺序。
- `docs/02-素材清单.md`：可直接填写的素材收集表。
- `docs/03-交接与开发计划.md`：本地文件组织、功能拆分与 GitHub 备份计划。
- `assets-originals/`：本地原始素材，不默认纳入 Git；人物参考为用户提供的徒步照片。
