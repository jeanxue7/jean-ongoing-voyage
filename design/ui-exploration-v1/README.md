# UI 视觉探索 v1

本轮使用 imagegen、imagegen-frontend-web 技能与内置 image_gen 工具生成 3 张独立横向概念图。它们用于评估视觉方向，不是已实现的网页。

- `01-hero.png`：首屏，人物、森林与雪山路线，用户提供的中英文主张。
- `02-places.png`：Places That Changed Me，三处山野故事入口，参考用户的尼泊尔照片。
- `03-bar.png`：后话客厅首页入口，参考用户的唱片墙照片，连接未来独立页。
- `prompts.json`：三张图片的完整生成提示词。

共同方向：暖白纸张底色、深绿文字、红色强调、蓝色远山；保留黄帽、墨镜、红衣、蓝包和黄绿裤的人物特征。

## 检视与后续处理

三张均为 1672 × 941。已检查整体构图、人物识别特征、主要标题、按钮与首屏中文。本轮未制作手机布局或动效。

模型额外添加了少量路牌、手写装饰文案；这些并非用户定稿，实施时移除或替换。山野图是叙事示意而非真实地图，山形、线路与个别中文标记需在正式制作时校准。酒吧照片区域经过生成模型重绘，正式页面应换回用户原始照片，避免将新增空间细节当作实景。

本轮方案建议：保留首屏的景观与人物关系；后续可适当缩小人物，留更多文字呼吸空间。酒吧入口保留摄影与手绘小人结合的方式。文字在前端中用真正的可编辑文本实现，不把整张图当网页。
